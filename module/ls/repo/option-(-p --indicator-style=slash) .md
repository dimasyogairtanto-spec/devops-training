### ``` -p --indicator-style=slash ```


### Cara penggunaan 


command ini di gunakan pada sistem operasi berbasis Linux untuk menambahkan tanda garis miring (/) di akhir nama direktori dalam output ls.

Dengan kata lain, opsi ini membantu membedakan antara file dan direktori secara visual.
